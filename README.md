# vim-fps

**マウス禁止。Vim のキーだけで戦うブラウザ FPS。**

移動・視点・アイテム選択がそれぞれ別の「モード」になっていて、同時には使えません。
FPS の経験よりも、どのモードで何をするかの判断と、キー入力の正確さが勝負になります。

- ブラウザで遊べます: **https://igarinpiano.github.io/vim-fps/** (練習モード / トンネルのサーバーへの接続)
- マルチプレイは CLI (`vimfps`) でホストします。LAN か Cloudflare Quick Tunnel で配信します
- 個人戦 (フリー・フォー・オール)。全員の基本性能は同じで、違いは拾った装備だけです
- 丘や谷のある 400 m 四方の野外マップ。建物 24 棟、岩・低い壁 各 170、木箱 110、木 420 本があり、高所から撃ち下ろす・稜線や遮蔽物に隠れる、といった立ち回りができます
- **戦車** (3 両) に乗れます。**リング** (段階的に縮む円) の外にいると体力が減ります
- 設定は **`.vimfpsrc`** (Vim の vimrc と同じ書き方) 1 つにまとめて書けます。ホストのオプションも同じファイルに書けます
- テクスチャ・効果音・UI の色は **スキン** (`skin.json` のあるフォルダーか zip) にまとめて、ドロップで入れたり、ホストから全員に配ったりできます。`:mkvimrc!` で設定とスキンを zip 1 つに書き出せます → **[設定ファイルとスキンの説明](docs/config.md)** ([サイト版](https://igarinpiano.github.io/vim-fps/docs/config.html))
- スマートフォン・タブレットでは画面上のキーパッドで遊べます (`:set touch=on/off`)。キーは場面 (メニュー・戦闘・戦車・観戦など) ごとに切り替わります

## 遊び方

### 1 人で練習する
https://igarinpiano.github.io/vim-fps/ を開いて選びます (ブラウザ内で動くのでサーバーは不要です)。

- **射撃訓練場**: 10〜400 m に的 (左右に動く的・遮蔽物の陰の的もあり) が並ぶ長い射撃場。後ろの台に全武器と回復・グレネード・弾薬があり、`y` で持ち替えます。弾は減らず、的は倒しても 1 秒で戻ります。当てたダメージが数字で出ます
- **カスタムマッチ**: bot の数 (0〜100 体。多いほど重くなります)、bot の強さ (5 段階)、ルール (復活あり / 復活なし)、時間、終了キル数、リング・戦車のあり / なし、マップ (ランダムかシード番号) を選んで始めます。`j`/`k` で項目、`h`/`l` で値 (`H`/`L` で 5 ずつ)、`Enter` で開始。前回の設定を覚えています
- **練習する**: bot と個人戦
- **練習する (復活なし)**: 最後の 1 人が勝つラウンド制。倒されると、倒した相手の視点で観戦します

### インストール
**Linux / macOS / FreeBSD / NetBSD / illumos / Android (Termux)**

```bash
curl -fsSL https://igarinpiano.github.io/vim-fps/install.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/igarinpiano/vim-fps/main/scripts/install.ps1 | iex
```

OS と CPU を判定して [Releases](https://github.com/igarinpiano/vim-fps/releases) から合うファイルをダウンロードし、`SHA256SUMS` で確かめてからインストールします。

- インストール先: `~/.local/bin` (Termux では `$PREFIX/bin`、Windows では `%LOCALAPPDATA%\Programs\vimfps`。Windows ではユーザーの PATH にも追加します)
- Linux では、どのディストリビューションでも動く静的リンク版 (musl) を選びます
- 環境変数 `VIMFPS_VERSION=1.1.1` で版を指定、`VIMFPS_INSTALL_DIR` で置き場所を指定できます
- スクリプトは [`scripts/install.sh`](scripts/install.sh) と [`scripts/install.ps1`](scripts/install.ps1) にあります。手動で入れる場合は Releases から `vimfps-<版>-<ターゲット>` を展開してください

### 友だちと遊ぶ (ホスト)

```bash
vimfps host
```

表示された `http://<LAN の IP>:7777/` を同じネットワークの人が開けば参加できます。

ホストは起動のたびに GitHub Pages から**最新の Web クライアント**を取得して配信します (10 分ごとにも確認)。
取得できないとき (オフラインなど) や、公開版のプロトコルがこの CLI と合わないときは、CLI に埋め込まれた版を使います。

インターネット越しに遊ぶときは [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) を入れて:

```bash
vimfps host --tunnel --password 合言葉
```

`https://….trycloudflare.com/#pw=合言葉` という URL (と QR コード) が出るので、それを共有します。
URL は起動のたびに変わります。

#### 管理者 (試合の開始と終了)
試合は**管理者**が始めます。ホストを起動しても試合は始まらず、参加した人は「待機中」の画面で待ちます (観戦のキーでマップを見て回れます)。
待っている間にホストのページで**射撃訓練場や練習**をしていても、管理者が試合を始めると**自動で練習を終えてサーバーに参加**します (タスクバーにサーバーの状態が出ます。`:set noautojoin` で知らせるだけにして、`:join` で参加)。
管理者は試合に出ず、全員の様子を見ながら試合を動かします。参加者は試合を始めることも、終わらせることも、ルールを変えることもできません (射撃訓練場や練習・設定は、これまでどおり各自で使えます)。

- **管理ページ** (`/admin.html`): 起動時に表示される `http://localhost:7777/admin.html#key=…` を開きます。鍵はアドレスバーからすぐ消えます (配信に映りません)
  - 全員の**視点**をタイルで一覧 (クリックで 1 人を大きく。赤い枠は撃ち合い中)、または大きな**マップ**で表示
  - 先頭のタイルは**カメラ**です。**自動** (`a`) は観戦の自動カメラと同じく見どころを追い、1 対 1 なら両方の体力を下に出します。**手動** (`o`) では CAMERA モードで `k`/`j` 前後・`h`/`l` 旋回・`H`/`L` 横・`K`/`J` 上下・`u`/`d` 見上げる / 見下ろす・`O` 真上から (マウス・指ではドラッグで向き、ホイールで前後、タッチではボタンで移動)。`Esc` で抜けます
  - `F` (または □ ボタン、`:fs`) でモニターを**全画面**に。タイルを `Enter` で 1 つだけ大きくすると、カメラや 1 人の視点を全画面で見られます
  - タイルの数は、画面の大きさに合わせて自動で決まります。全員が見やすい大きさで入るなら全員、入らなければ画面に入るだけ (15、19、27 … どんな数でも。行は端まで埋まります) を 1 ページにします。**一度に出す数** (1〜64) を自分で選ぶこともでき、入りきらない分はページに分かれます (ページは手で送るか、5〜30 秒ごとに自動で巡回)。選んだ数はそのブラウザーに残ります
  - タイルの**並び**は、いまの**順位**か、**名前順** (五十音・アルファベット順。bot-2 は bot-10 より前) を選べます (`s`)
  - **スマートフォン**でも使えます。縦 1 列に並び、試合の操作がいちばん上に来ます。キーの代わりに、どの操作もボタン (◀ ▶、「観戦に回す」「退出させる」「: コマンド」「全員にメッセージ」) で行えます
  - 順位・HP・キル・デス・**ping** (参加者のブラウザーが測った往復時間)、マップ (全員の位置と見ている向き)
  - 試合を開始 (秒読みつき)・取り消し・終了 (結果を出して待機へ)・中止 (すぐ待機へ)、ルール (時間・キル数・bot の強さ・復活・リング・戦車。待機中・秒読み中はこれから始まる試合のルールで、保存するとすぐ反映。試合中・結果の間は次の試合のルール)、結果のあと自動で次の試合へ進むか、参加者を観戦に回す・退出させる、全員へのメッセージ
  - **bot**: **強さごとの数** (強さ 5 を 5 体、強さ 4 を 2 体 …) でそろえられます。合計の数や 1 体ずつの強さ (1〜5) も変えられます。どれもすぐ反映されます (試合中でも)。強さを指定していない bot は、ルールの「bot の強さ (全体)」に従います
  - ルールで「bot の強さ (全体)」を変えて保存すると、すでにいる bot も変えるか聞きます (`y` 全員変える · `n` いまの強さのまま · `Esc` 保存しない)
  - **bot の番号** (bot-1, bot-2 …) の振り方: **強い順**・**弱い順**・**ランダム**。待機中・秒読み中はすぐ、試合中は次の試合の開始時に振り直します (試合の途中で名前は変わりません)
  - ゲームと同じ XP 風の画面で、**Vim のキーだけで全部操作できます** (マウスも使えます)。`?` でキーの一覧

    | キー | 動作 |
    |---|---|
    | `gt` / `gT` / `{n}gt`、`Tab`、`Ctrl-w w` / `Ctrl-w hjkl` | ウィンドウを移る (1 モニター · 2 試合 · 3 マップ · 4 順位 · 5 bot · 6 ルール · 7 ログ) |
    | `j` / `k`、`gg` / `G`、`h` / `l` (`H` / `L` で 5 ずつ)、`Enter` | ウィンドウの中で選ぶ・値を変える・実行 (`{count}` も使えます) |
    | `:` | コマンド (下のホストの端末と同じもの。`:w` でルールを保存、`:q` でログオフ) |
    | `i` | 全員にメッセージ |
    | `m` | モニターを 視点 / マップ で切り替え |
    | モニターで `hjkl` · `Enter` · `b` · `s` | 選手を選ぶ · 1 人を大きく · bot の視点も出す · 並び (順位 / 名前順) |
    | モニターで `+` / `-` · `=` · `]` / `[` (`Ctrl-f` / `Ctrl-b`) · `c` | 一度に出す数を 1 つずつ増やす / 減らす · 自動 (画面に入るだけ) · 次 / 前のページ · ページの巡回 |
    | 順位で `w` · `dd` | 観戦に回す · 退出させる (`y` / `n` で確認) |
    | bot で `h` / `l` · `a` | 強さごとの数・合計・番号の振り方・1 体の強さを変える · 全体の強さに戻す |
- **ホストの端末**: 起動した端末にそのまま入力します。`help` で一覧

| コマンド | 動作 |
|---|---|
| `status` (`s`) | 状態と参加者の一覧 (HP・キル・デス・ping) |
| `start [秒]` | 試合を開始 (既定 5 秒の秒読み。`start 0` ですぐ) |
| `cancel` | 開始の秒読みを取り消す |
| `end` | 試合を終了 (結果を出して待機中へ) |
| `lobby` | すぐ待機中に戻す (結果なし) |
| `auto on` / `auto off` | 結果のあと、次の試合を自動で始めるか (既定 off: 待機中に戻る) |
| `set time=10 frags=25 bots=5 skill=3 respawn=on ring=on tanks=on` | ルール (書いた項目だけ変わります)。待機中・秒読み中はこれから始まる試合、試合中は次の試合。`skill` を変えても、いる bot の強さはそのまま |
| `bots 数` | bot の数をすぐ変える (0〜500。増えた bot は全体の強さ) |
| `bots 5:5 4:2` | 強さごとの数ですぐそろえる (強さ 5 を 5 体、強さ 4 を 2 体、ほかは 0) |
| `order strong` / `order weak` / `order random` | bot の番号の振り方 (強い順 / 弱い順 / ランダム) |
| `level 名前 1〜5` / `level 名前 auto` | bot 1 体の強さをすぐ変える (`auto` で全体の強さに戻す) |
| `level all 1〜5` / `level all auto` | bot 全員の強さをすぐ変える |
| `kick 名前` / `kick 番号` | 退出させる |
| `watch 名前` / `watch 番号` | 観戦に回す |
| `say テキスト` | 全員にメッセージ |
| `admins` | 管理ページの URL (鍵つき) |

**管理者になれる人**: 鍵を知っている人だけです。

- 何も指定しなければ、起動のたびに鍵を 1 つ作って表示します (この端末を見られる人が管理者)
- 決まった人を管理者にするには `--admin 名前:鍵` (鍵は 8 文字以上。何人でも)。環境変数 `VIMFPS_ADMIN=名前:鍵,名前:鍵` でも指定できます (Codespaces のシークレットに入れておけます)。指定した鍵は画面に出さず、`admins` と入力したときだけ表示します
- 同じアドレスから鍵を 5 回間違えると、1 分間は入れません

**Codespaces や配信で使うとき**: 管理ページを参加者と別のポートにできます。

```bash
vimfps host --admin-port 7778                  # 管理ページは 7778 だけ (7777 では管理できない)
vimfps host --tunnel --admin-tunnel            # 参加者用と管理用に別々の Quick Tunnel
```

- Codespaces では、参加者用のポート (7777) を公開にし、管理用のポート (7778) は**非公開のまま**にします。非公開のポートは Codespace の持ち主しか開けないので、鍵と合わせて二重に守られます
- `--admin-tunnel` は管理ページ用の Quick Tunnel をもう 1 つ起動し、その URL を表示します (参加者用の URL では管理できません)
- `--autostart` にすると以前の動き (起動したら試合が始まり、結果のあと自動で次の試合) になります

| オプション | 説明 |
|---|---|
| `--port 7777` | 待ち受けポート |
| `--bind 127.0.0.1` | LAN に公開しない |
| `--tunnel` | Cloudflare Quick Tunnel で公開 |
| `--password PW` | 合言葉 (URL の `#pw=` で渡す) |
| `--bots N` | bot を入れる (0〜500。150 体を超えるとホストの処理が追いつかず、試合がゆっくりになります) |
| `--bot-skill 1〜5` | bot の強さ (下の表) |
| `--max-players 100` | 最大人数 (bot・観戦を除く。いくつでも指定できます。観戦は別に 200 人まで) |
| `--time-limit 10` | 1 試合の分数 |
| `--frag-limit 25` | このキル数で試合終了 |
| `--seed N` | マップのシード |
| `--no-respawn` | 復活なし: 最後の 1 人が勝つラウンド制 (倒された人は観戦、次のラウンドで全員復帰) |
| `--no-ring` | リングなし |
| `--no-tanks` | 戦車なし |
| `--web URL` / `--web embedded` | 配信する Web クライアント (既定: GitHub Pages の最新版) |
| `--no-network-check` | macOS: 起動時のファイアウォールの確認 (下) をしない |
| `--skin DIR` | 参加者全員に配るスキン (`skin.json` のあるフォルダー) |
| `--config PATH` | 設定ファイル (既定: `~/.vimfpsrc`) |
| `--no-config` | 設定ファイルを読まない |
| `--admin 名前:鍵` | 管理者 (複数可。省略時は鍵を作って表示)。環境変数 `VIMFPS_ADMIN` でも |
| `--admin-port PORT` | 管理ページを別のポートで配信 (参加者用のポートでは管理できなくなる) |
| `--admin-bind ADDR` | 管理ページのポートの待ち受けアドレス (既定 `127.0.0.1`) |
| `--admin-tunnel` | 管理ページを別の Quick Tunnel で公開 (`--admin-port` が無ければ PORT+1) |
| `--autostart` | 管理者を待たずに試合を始め、結果のあと自動で次の試合へ |

これらのオプションは `~/.vimfpsrc` の `host` の行にも書けます (`--` を取った名前。コマンドラインのほうが優先)。
`vimfps config` で読まれる内容を確認、`vimfps config --init` でひな形を作れます。くわしくは [設定ファイルとスキン](docs/config.md#vimfps-host-で使う)。

```vim
" ~/.vimfpsrc
host bots=5 bot-skill=4 time-limit=15
host tunnel password=合言葉 skin=./my-skin
```

#### macOS のファイアウォール

macOS のファイアウォールが有効だと、`vimfps` に規則が無いか遮断する規則があるとき、ほかの端末からの接続が届きません (規則が無いときは、システムのダイアログで許可するまで届きません)。
`vimfps host` は待ち受けを始める前にこれを調べ (`socketfilterfw` に管理者の権限なしで尋ねます)、通らないときは `[y/N]` で聞きます。
`y` のときだけ次の 2 つを `sudo` で実行し (パスワードは `sudo` が聞きます)、もう一度確かめます:

```bash
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add ~/.local/bin/vimfps
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --unblockapp ~/.local/bin/vimfps
```

- 断ったとき・端末でない (パイプやスクリプト) ときは、何も変えずに直し方を表示して、そのまま起動します
- 手で許可するときは「システム設定 → ネットワーク → ファイアウォール → オプション…」で `vimfps` を「外部からの接続を許可」にします
- `vimfps update` で実行ファイルが入れ替わると、もう一度聞かれることがあります
- `--no-network-check` で確認しません

### bot の強さ
| 段階 | 見える距離 | 反応 | 照準のぶれ | 振り向き | 偏差撃ち | 回り道 |
|---|---|---|---|---|---|---|
| 1 とても弱い | 70 m | 0.9 s | ×2.4 | 遅い | なし | ぶつかってから |
| 2 弱い | 110 m | 0.6 s | ×1.6 | やや遅い | なし | ぶつかってから |
| 3 普通 | 150 m | 0.35 s | ×1.0 | 普通 | なし | 歩き出す前に |
| 4 強い | 170 m | 0.25 s | ×0.6 | 速い | あり (動く相手の先と落下を狙う) | 歩き出す前に |
| 5 とても強い | 200 m | 0.15 s | ×0.3 | とても速い | あり | 歩き出す前に |

**回り道**: 行き先 (リングの中、物音、回復キットなど) との間に壁や建物があると、bot はマップの通れる場所をたどって回り道を探します (建物の中からなら、ドアから出ます)。
段階 3 以上は歩き出す前に、間がふさがっていないかを 0.5 秒ごとに確かめて道を決めます。段階 1・2 はまっすぐ歩き出し、ぶつかって 2 秒ほど進めなくなってから道を探します。
戦車に乗っている bot は回り道を探しません (戦車はドアを通れないので、別の行き先を試し、だめなら降ります)。

段階 4・5 の bot は、戦車の使い方も賢くなります:

- 空の戦車を遠くから見つけて乗りに行きます (段階 1〜3 は 30 m 以内、4 は 60 m、5 は 90 m。行き先に戦車を選ぶ割合も 3 割 → 6 割 → 8 割)。物音より戦車を優先します
- 撃ち合いの最中でも、すぐそば (15 m 以内) か、敵よりずっと近く (45 m 以内で敵までの半分以下) に空の戦車があれば乗り込みます
- 体力が 55 未満のとき・リロード中は、近く (25 m 以内) の空の戦車の、敵から見て裏側に回り込んで隠れます。隠れたらしゃがんで、敵が見えなくなっても 3 秒はそこを動かず、回復キットがあれば使い終わるまで動きません
- 戦車に乗った敵には、8〜32 m ならグレネードを投げます (銃弾は 15% しか通らないため)

戦車は bot の視線も遮ります (どの段階でも、戦車の向こう側は見えません)。グレネードは戦車に当たると跳ね返ります。

(反応は遠い相手ほど遅くなります: + 距離 / 250 秒)。練習中は `:bots N` で数、`:botskill N` で強さを変えられます。

### 観戦
- ホストのページのメニューで「このサーバーを観戦」を選ぶと、試合に出ずに見られます (観戦者は人数制限に数えません)。`:play` で途中参加、`:watch` で観戦に戻ります
- 復活なしの試合で倒されると、ブルースクリーンのあと**倒した相手の視点**の中継になります (`:set nokillcam` にすると自由視点)
- 観戦中のキー (SPECTATE モード):

| キー | 動作 |
|---|---|
| `a` | **自動カメラ**の入 / 切 (`:auto` でも)。切ると、映していた選手の視点になります |
| `n` / `N` | 次 / 前の選手を追う (`:follow 名前` でも)。自動カメラ中は、映す選手だけを替えます |
| `o` | 自由視点 (`k`/`j` 前後、`h`/`l` 旋回、`K`/`J` 上下、`u`/`d` 見上げる・見下ろす、Shift で速く、`,` `.` で 45°) |
| `O` | 空からの視点 (真上から見下ろす。`hjkl` で移動、`K`/`J` で高さ、`u`/`d` で見下ろす角度 (画面の真ん中を中心に斜めから見る)、Shift で速く、`,` `.` で回転)。全員に ▼ と名前が付きます |
| `m` | マップ: 観戦中は全員の位置・向き・名前・HP が出ます (追っている人は黄色)。**自分の視点** (カメラの位置と見ている範囲) も黄色の扇形で出ます。選手の視点・自動カメラ・自由視点・空からの視点のどれでも同じです |
| `i` / `:` | チャット / コマンド |

観戦中は、追っている選手の視点 (構え・スコープも含む) と、左上のカード (名前・HP ゲージ・武器・構え・キル / デス) が見えます。
撃ち合いの最中は、カードに**相手の名前と体力**も出ます (自動カメラが 1 対 1 を映しているとき、または直前に撃ち合った相手)。
画面の上の表示 (コンパス・キーの説明・カード・人数) は重ならないように並びます。狭い画面では、コンパスとキーの説明が上、カードがその下になり、コンパスは右上の人数を避けて左に寄ります。
その選手が撃つと、自分で撃ったときと同じように、銃口の光・反動・弾の軌跡が見え、銃声も自分の銃のように聞こえます。当てたときのヒットマークとダメージの数字、撃たれたときの赤い方向表示も出ます (自動カメラの小窓と、管理ページのタイルでも同じです)。

#### 自動カメラ (中継視点)
観戦で入ると (`:watch` も)、まず**自動カメラ**になります。選手を外から映す 3D の中継視点で、何もしなくても見どころを追います。

- 映し方は 4 つ: 斜め上から選手のまわりを回る / 肩越しに進む先を映す / 選手を手前に、撃ち合っている敵を遠くに映す / 高い位置から広く映す
- 撃ち合い・命中・キルの多い選手を選び、7〜12 秒ごと (よそで激しい撃ち合いが始まればすぐ) に次の選手へ移ります。映していた選手が倒されると、少し間をおいて倒した相手へ移ります
- 切り替えはカットせず、カメラが上空を通って滑らかに飛んでいきます。壁や丘で選手が隠れるときは、回り込むか近づいて映します
- 画面が広いとき (幅 900 px・高さ 540 px 以上、タッチパッドなし) は、右下の小窓 (ワイプ) に映している選手本人の視点が出ます (`:set noautopip` で消す)
- 映している選手には黄色の ▼ が付き、上の帯に「選手 vs 敵」が出ます
- `:set noautocam` にすると、観戦は今までどおり選手の視点から始まります。復活なしで倒されたあとは倒した相手の視点から始まり、`a` で自動カメラになります

## 操作

`Esc` の代わりに `Ctrl-[` も使えます (ブラウザは `Esc` でフルスクリーンを抜けるため)。

### NORMAL (移動)
| キー | 動作 |
|---|---|
| `h` `j` `k` `l` | 左・後・前・右に歩く (前進キーは `:set forward=k` / `j`) |
| `Shift` を押している間 | スニーク (遅い・足音が小さい・頭が低い) |
| `{n}k` など | n メートル歩く |
| `,` / `.` | 左 / 右に 45° 旋回 (`{n},`、角度は `:set turnangle`) |
| `~` | 180° 振り返る |
| `f` | 撃つ / 選んでいるアイテムを使う (腰撃ちは弾が散る) |
| `{n}dd` | グレネードを投げる (n=1〜5 で強さ、省略時 3) |
| `r` | リロード |
| `y` | 足元の銃を拾う (銃は 2 丁まで。持っている銃と交換) |
| `e` | 戦車に乗る / 降りる (近くにいるとき。下の「戦車」) |
| `gt` | 2 丁の銃を持ち替え |
| `*` | 照準の近くに見えている敵をマーク (6 秒間、壁越しでも ▼ が見える) |
| `s` | インベントリ |
| `m` | マップ |
| `i` | チャット (全員に届きます。スマホでは「取り消し」ボタン、ウィンドウの ×、パッドの Esc で閉じる) |
| `:` | コマンド |

割り当てのないキーは何もしません。

### VIEW (`v`: 構える。歩けません)
| キー | 動作 |
|---|---|
| `h` `j` `k` `l` | 視点移動 (カーソルと同じ向き)。短く押すと 1 目盛り (0.2°)、押し続けるとゆっくり回り続ける (微調整)。**1 段階目 (構え) では押し続けても等速** (`:set adssens`、既定 24°/秒)、**2 段階目 (`v` をもう一度: スコープ) では、しばらくすると加速**します |
| `H` `J` `K` `L` | 速く回す |
| `{n}l` など | n 目盛り回す |
| `v` | スコープの倍率を切り替え (SR は構えた時点で低倍率スコープ、`v` で高倍率) |
| `f` | 撃つ |
| `{n}dd` | 狙って投げる |
| `*` | 敵をマーク |
| `Esc` | NORMAL へ |

### INVENTORY (`s`)
縦のリストで、`j` / `k` で銃・回復キット・グレネードを選び、`Enter` / `Esc` で閉じてから `f` で使います。
`gg` / `G` / 数字でも選べます。

### 戦車
マップに 3 両 (射撃訓練場にも 1 両) 止まっています。近く (4.5 m 以内) で `e` を押すと乗り込めます。

| キー | 動作 |
|---|---|
| `k` / `j` | 前進 (9 m/s) / 後退 (4 m/s) |
| `h` / `l` | 車体を左 / 右に旋回 (52°/秒)。砲塔 (視点) も一緒に回ります |
| `v` | 砲を構える (VIEW)。`hjkl` で砲塔を回して狙います。構えている間は走れません |
| `f` | 砲撃。砲弾は初速 200 m/s で飛び、重力で落ち、着弾すると爆発します (半径 6 m、最大 150 ダメージ、直撃は即死)。装填 3 秒 |
| `,` `.` `~` | 砲塔だけを回す |
| `e` | 降りる |

- 戦車の HP は 400。**銃弾は 15% しか通りません**。グレネードと砲弾の爆発はそのまま効きます (砲弾の直撃は +100)
- 中にいる間、銃弾や爆発では傷つきません。戦車が壊されると爆発し、中の人も倒れます (倒した人のキル)
- 走っている戦車 (3 m/s 以上) にひかれると倒れます。止まっている戦車は通り抜けられません
- 壊された戦車は 45 秒後に元の場所へ戻ります。戦車に乗っている間は、銃・回復キット・グレネードは使えません
- bot も、近くに空の戦車があれば乗ります (強い bot ほど積極的に乗り、陰に隠れもします: 上の「bot の強さ」)。`--no-tanks` (カスタムマッチでは「戦車: なし」) で無くせます

### リング
試合が始まってしばらくすると、**リング** (オレンジ色の光の壁) が縮み始めます。壁の外にいる間は体力が減り続けます (戦車の中でも)。

- 5 段階で縮みます: 半径 180 → 120 → 76 → 48 → 30 m。各段階の円は、前の円の中のどこかに決まります
- 外にいる間のダメージは毎秒 2 → 3 → 5 → 8 → 12 → 15 (段階が進むほど大きい)
- 「待ち」と「縮む時間」はどちらも試合時間の 8% (10〜60 秒。10 分の試合なら 48 秒ずつ、8 分で最終の大きさ)。復活なしの試合では最長 24 秒ずつ
- 右上に段階と残り時間、マップ (`m`) に今の円 (赤) と次の円 (白の破線) が出ます。外に出ると画面の縁が赤くなり、コンパスに円の中心の方向 (◆) が出ます
- 復活する場所は次の円の中から選ばれます。bot も円の中へ戻ります
- `--no-ring` (カスタムマッチでは「リング: なし」) で無くせます。射撃訓練場にはありません

### 索敵
- 画面上の**コンパス**に、銃声 (赤 ●、3.5 秒)、近くを走る敵の足音 (橙 ●、35 m 以内)、マークした敵 (黄 ▼) の方向が出ます。スニーク中の足音は出ません
- 見えている敵の頭上に赤い ▼ が付きます (`:set nomarkers` で消す)
- マップ (`m`) にも最近の銃声が赤い輪で出ます
- キルの通知と倒されたときのダイアログに、相手との距離が出ます

### 名前と体力ゲージ
- 他の選手の頭上に**名前**が出ます (`:set nonameplates` で消す)
- 名前の下に**体力ゲージ**が出ます (緑 → 黄 → 赤)。対戦中のプレイヤーには相手の HP は送られないので、ゲージが出るのは**観戦中**と**オフライン練習・射撃訓練場**だけです (`:set nohpbars` で消す)

### テクスチャ (`:texture`)
地形 (形) はそのままで、面の色を自分の画像に置き換えられます。貼れる場所は `ground` (地面) / `wall` (建物の壁) / `roof` (屋根) / `rock` (岩) / `cover` (低い壁) / `crate` (木箱) / `trunk` (木の幹) / `fence` (外周のフェンス) / `leaves` (木の葉) / `tank` (戦車) / `sky` (空: 横長のパノラマ画像)。

```vim
:texture                   " 一覧と使い方
:texture ground            " 画像ファイルを選んで地面に貼る
:texture load              " 複数のファイルをまとめて選ぶ (ファイル名の先頭で場所を決める: ground.png, wall-brick.jpg …)
:texture ground URL        " URL の画像を貼る
:texture ground size 12    " 1 枚の画像が覆う大きさ (メートル)
:texture ground none       " 元の色に戻す
:texture reset             " すべて元に戻す
```

- 画像ファイルをページへドラッグ & ドロップしても貼れます (ファイル名で場所を決めます)
- 選んだ画像はそのブラウザーに保存され (IndexedDB)、次に開いたときも使われます。ほかの人の画面には影響しません。どのスキンよりも優先します
- 何枚もまとめて持ち運ぶ・全員に同じ見た目を配るには **スキン** を使います ([設定ファイルとスキン](docs/config.md#スキン))
- 壁や箱は大きさに関係なく同じ縮尺で繰り返し貼られます。当たり判定は変わりません

### 効果音のファイル (`:sounds`)
次の場面で音声ファイルを鳴らします。どのファイルを鳴らすかはスキンの `skin.json` の `"sounds"` に書きます ([設定ファイルとスキン](docs/config.md#sounds-効果音))。公開版には XP 風の音が入っています。

| 名前 | 鳴る場面 |
|---|---|
| `startup` | スポーン時 (起動音) |
| `error` | キルされた時 (エラー音) |
| `error2` | 被弾した時 (ダメージを受けるたび。リングの外のダメージも) |
| `shutdown` | 試合終了時 (システム終了音) |

wav / mp3 / ogg を読みます。ファイルが無い場面では何も鳴りません (`error2` だけは、無ければ合成音が鳴ります)。`:sounds` で、どのスキンのどのファイルが鳴るか確認できます。

### 空間オーディオ (`:set spatial`)
音の方向と距離に加えて、まわりの地形や建物で音が変わります (初期値でオン)。

- **空気**: 遠くの音ほど高い音が減って、こもって聞こえます (100 m で約 6 kHz から上、300 m で約 2.6 kHz から上が下がる)
- **壁・丘**: 自分と音のあいだに建物の壁・岩・遮蔽物・木箱・丘があると、こもって小さくなり、響きの割合が増えます (壁の向こうの足音・銃声が分かる)。木の幹とフェンスは音を遮りません
- **響き**: 屋根の下 (建物の中) では短く近い響き、外では遅れて薄く長い響き (遠くの地形からの返り)。建物に出入りすると切り替わります。自分の銃声や足音も響きます
- **上下**: ヘッドホンでは、見上げる・見下ろすと頭の向きに合わせて上下の音の聞こえ方も変わります

```vim
:set nospatial         " 方向と距離だけ (こもり・壁・響きなし)
:set reverb=50         " 響きを半分に (0〜200%、0 で響きなし)
```

**OS やヘッドホンの空間オーディオとの組み合わせ**
- **Windows Sonic / Dolby Atmos for Headphones / DTS Headphone:X**: これらをオンにすると、出力が 7.1 チャンネルとして見えることが多いので、`:speakers auto` (または `7.1`) にすると OS 側の立体音響で鳴ります。`:speakers` に出る「最大」が 8 なら 7.1 で出ています
- **Apple の空間オーディオ (AirPods など)**: ブラウザーからはヘッドトラッキング (頭の向き) を受け取れません。macOS / iOS の「ステレオを空間化」をオンにすると、このゲームの立体音響の上にさらに掛かって前後が分かりにくくなるので、オフにして `headphones` のまま遊ぶのがおすすめです
- 高さ方向のスピーカー (Dolby Atmos の 7.1.4 など) へは、ブラウザーからは出せません

### サラウンド (`:speakers`)
初期値はヘッドホン用の立体音響 (HRTF。2 チャンネルで左右・前後・上下が分かる) です。スピーカーで遊ぶときは、スピーカーの数だけチャンネルを出せます。

```vim
:speakers 5.1                 " 5.1ch (L R C LFE SL SR)
:speakers 7.1                 " 7.1ch (L R C LFE BL BR SL SR)
:speakers auto                " 出力のチャンネル数で選ぶ (8 → 7.1、6 → 5.1、4 → quad、2 → headphones)
:speakers stereo              " スピーカー 2 本 (立体音響の加工なしで左右に振り分け)
:speakers headphones          " ヘッドホン (初期値)
:speakers                     " 今の出し方・出力のチャンネル数・チャンネルの順番
:speakers test                " 各スピーカーから順に音を出して確かめる
:set speakers=5.1             " :speakers と同じ (.vimfpsrc にはこの形で書く)
```

- 銃声・足音・爆発などは、その方向の両隣のスピーカーから鳴ります (VBAP。音量の合計は一定。高さは使いません)。鳴っている間に向きを変えると、音もついてきます。すぐそばの音は全部のスピーカーに広がります
- 起動音・被弾音など方向のない音は左右のフロントから、サブウーファー (LFE) にはすべての音の 120 Hz 以下を少し送ります
- OS の音声出力を 5.1 / 7.1 にしておく必要があります (Windows: サウンドの設定 → スピーカーの構成)。出力が 2 チャンネルのままだと、ブラウザーは 2 チャンネルしか出せず、`5.1` にしても `stereo` で鳴ります (`:speakers` に出力のチャンネル数が出ます)
- 7.1 のチャンネルの順番は OS と機器によって違うことがあります。`:speakers test` で、表示と鳴る場所が合っているか確かめてください

### イコライザー (`:eq`)
すべての音 (銃声・足音・効果音) に EQ を掛けられます。`:eq` で今のカーブのグラフとプリセットの一覧が出ます。設定は `:set eq=…` なので、ブラウザーに保存され、`:mkvimrc` で `.vimfpsrc` に書き出されます。

```vim
:eq bass                      " プリセット (bass / bassboost / treble / loudness / steps / voice / night)
:eq steps                     " 足音を聞き取りやすく (低音を抑えて 2〜4 kHz を強く)
:eq ls100:+6,pk3k:+3:1.4      " 自分で書く: 100 Hz 以下 +6 dB、3 kHz +3 dB (Q 1.4)
:eq bass,hs8k:+2,pre-2        " プリセットに足す。pre はプリアンプ (dB)
:eq load                      " Equalizer APO / AutoEq のファイル (ParametricEQ.txt) を読み込む
:eq off                       " EQ なし
:set eq=bass                  " :eq と同じ (.vimfpsrc にはこの形で書く)
```

- フィルター 1 つは `種類 周波数 : ゲイン(dB) : Q`。種類は `pk` (ピーク、省略時)・`ls` (ローシェルフ)・`hs` (ハイシェルフ)・`lp` / `hp` (ローパス / ハイパス。ゲインなしで `hp60` や `hp60::0.7`)。周波数は Hz で、`k` を付けると kHz。Q を省くとピークは 1、ほかは 0.707。最大 20 個
- Equalizer APO と同じ計算 (RBJ のバイクワッド) なので、[AutoEq](https://github.com/jaakkopasanen/AutoEq) のヘッドホン補正 (`ParametricEQ.txt`) をそのまま使えます。ファイルはページにドロップしても読み込めます
- 音割れを防ぐリミッターが最後に掛かります

### 通信統計
- `:set netstat` で右上に ping (平均・最小・最大・ゆれ)、受信間隔、通信量が常に出ます
- `:net` でくわしい一覧 (接続先、ping、スナップショットの受信間隔と最大の空き、通信量の毎秒・合計、サーバーの計算・送信レート) を開きます
- タイトルバーの ping は 1 秒ごとに測ります。練習モードでは、ブラウザ内のシミュレーションまでの往復時間です

## 仕様 (`:spec`)
ゲーム内で `:spec` を実行すると、遊んでいるサーバーの数値がそのまま表示されます。

- **弾は実際に飛びます。** 銃ごとの初速で撃ち出され、重力 9.81 m/s² で落ちます (空気抵抗なし: 位置 = 初速 × t + ½ × g × t²)。遠くの相手には、届くまでの時間の分だけ先を、落ちる分だけ上を狙います
- SR のスコープには落下の目盛り (1〜4 = 100〜400 m) が出ます。中心に近すぎて見分けられない距離の目盛りは省きます

- HP 100、頭の当たり判定は半径 0.25 m

- 腰撃ちで歩いていると拡散 ×1.3。構え (VIEW) 中は歩けません
- 移動: 走り 6 m/s、スニーク 2.6 m/s、加速度 40 m/s² (`:set nomoveaccel` で無限大)
- 回復キット +60 HP (1.6 秒、最大 3 個。使っている間に撃たれたりリングの外で削られたりしても止まりません。持ち替え・リロードで中断)。グレネード: 信管 3 秒、半径 7 m、最大 120 ダメージ (距離で減少、壁で遮られる、最大 3 個)、初速 `1dd`=9.5 〜 `5dd`=23.5 m/s。投げた人が爆発の前に倒されても、そのキルは投げた人のものになります (スコアに入り、キルの距離は投げた場所から測ります)。戦車の砲弾も同じです
- 復活 3 秒後、復活直後 3 秒は無敵 (撃つと解除)

## 設定 (`:set`)

Vim と同じ書き方です。設定はブラウザに保存されます。
`:mkvimrc` で設定ファイル (`.vimfpsrc`) に書き出し、`:source` で読み込めます (別のブラウザーへの引っ越しや、ホストの設定と一緒に管理するとき。[設定ファイルとスキン](docs/config.md))。

```vim
:set step=0.1          " 短押し・回数指定 1 回の角度 (既定 0.2°)
:set adssens=30        " 構え (1 段階目) で長押ししたときの速さ (度/秒、既定 24。加速なし)
:set sens=8            " スコープ (2 段階目) の長押しの初速 = 微調整の速さ (度/秒、既定 12)
:set accelafter=800    " 長押しがこの時間 (ms) を超えたら加速を始める (既定 450)
:set accel=600         " 加速度 (度/秒²)。inf で加速開始と同時に最高速、0 でずっと一定
:set maxspeed=360      " 最高速 (既定 220)
:set aimdelay=80       " 押しっぱなしが連続移動になるまで (ms)
:set zoomsens=0.5      " 構え・スコープ中の倍率。視点速度と 1 目盛りは元々ズーム率に比例して細かくなり (SR スコープなら約 0.18 倍、1 目盛り約 0.04°)、さらにこの値が掛かる
:set fov=100           " 視野角 (画面の縦方向の角度、既定 80)。120 を超えると魚眼になり、最大 360 で全方向が見える
:set touch=on          " タッチ用キーパッド (auto / on / off)
:set nocompass         " 索敵コンパスを消す
:set nokillcam         " 復活なしで倒されたら自由視点で観戦
:set nodmgnum          " ダメージの数字を出さない
:set nonameplates      " 頭上の名前を出さない
:set nohpbars          " 頭上の体力ゲージを出さない
:set netstat           " 通信統計 (ping・受信間隔・通信量) を表示
:set nospatial         " 空間オーディオ (壁越しのこもり・響き) を切る    :set reverb=50  響きを半分に
:set speakers=5.1      " サラウンド (headphones / stereo / quad / 5.1 / 7.1 / auto。:speakers で確認とテスト)
:set eq=bass           " イコライザー (:eq で一覧とグラフ)
:set invert            " 上下反転 (:set noinvert で戻す)
:set forward=j         " j を前進に
:set nosmooth          " アニメーション・補間・加速をすべてオフ
:set sens?             " 値を見る
:set sens&             " 初期値に戻す
:set all               " すべて表示
:options               " 一覧と説明
```

### 視野角 (`:set fov`)
`fov` は画面の**縦方向**に見える角度です (40〜360、既定 80)。`.vimfpsrc` に `set fov=150` と書いても同じです。

- **120 まで**: ふつうの遠近法の画面
- **120 を超えると**: 平らな画面では 180° 以上を映せないので、魚眼レンズのような画面になります。外側ほど縮んで映ります (120 のときの見え方からなめらかにつながります)
- **360**: 画面の上下の端が真うしろになり、画面の中の円に全方向が収まります (円の外は何も映りません)。横長の画面では、それより小さい値で左右の端が真うしろに届きます

16:9 の画面での横方向の角度: `fov=80` → 約 112°、`120` → 144°、`150` → 180°、`200` → 240°、`300` 以上 → 360°

構え・スコープ中はその銃の倍率の画面になります。魚眼のときは周りの 6 方向を描いてから合成するので、ふつうの画面より重くなります。観戦中の小窓 (ワイプ) は 120 までで表示します。

### アニメーションなしで遊ぶ
`:set nosmooth` で、滑らかにするための処理をすべて切ります。

| 個別の設定 | オフにすると |
|---|---|
| `noadsanim` | 構え・スコープが瞬時に切り替わる |
| `nomoveaccel` | 移動の加速度が無限大 (押した瞬間に最高速、離した瞬間に停止) |
| `noturnanim` | `,` `.` `~` の旋回が瞬時 |
| `nointerp` | 他プレイヤーを受信した位置にそのまま表示 |
| `nobob` | 歩行の揺れ・反動の表示なし |
| `nouianim` | 通知のフェードや爆発のアニメーションなし |

`:set smooth` で全部元に戻ります。

## ゲームのルール
- 個人戦。制限時間 (既定 10 分) か、誰かが規定キル数 (既定 25) に届いたら終了。結果を 10 秒表示したあと (人数が多いときは表を `j` / `k` でスクロール)、ホストでは待機中に戻り、管理者が次の試合を始めます (練習では自動で次の試合へ)
- 倒されるとブルースクリーン (倒した相手・武器・距離が出ます) になり、自動で再起動して 3 秒後に復活。最初は AR、回復キット 1、グレネード 1
- 復活する場所は、生きているほかの選手から**見えない**、遮蔽物のそばの地点から選びます (全員から見えない場所が無いときだけ、いちばん遠い地点)。始まった途端に撃たれにくくなっています
- bot は 150 m 先まで見え、120 m 以内の銃声と近くの足音を聞いてそちらへ向かいます
- bot は敵が見えないときに体力が 70 を切っていれば回復キットを使います (撃ち合いが始まると銃に持ち替え。体力 40 未満なら使い終わるまで続けます)。回復キットが無く体力が 60 未満なら、80 m 以内に落ちている回復キットを拾いに行きます
- bot は弾にも気を配ります: 撃ち合いで銃の弾が切れたら、もう 1 丁に弾があれば持ち替えます。予備の弾が尽きたら、敵がいないときに近く (90 m 以内) の弾薬を拾いに行きます。どの銃にも弾が残っていなければ、敵の前に立ち止まらず、グレネードがあれば投げ、弾薬か落ちている銃を拾いに行きます (拾った銃は弾が入っています)
- 武器: AR / SMG / SG / SR。頭に当てるとダメージが増えます (SR は頭なら 1 発)
- 構える (VIEW) と弾が集まり、スコープ (`v` をもう一度) でさらに集まります。SR は構えた時点で低倍率スコープです
- 回復キット (+60)、グレネード、弾薬はマップに落ちていて、歩いて触れると拾えます (丘の上のものも)
- 戦車とリングは上の「戦車」「リング」のとおりです

## 開発

```bash
scripts/build-wasm.sh           # 練習モード用の wasm を web/pkg/ に
cargo run -p vimfps -- host     # web/ を埋め込んだホストを起動
cargo test --workspace
node --test tests/web/*.test.mjs
```

| 場所 | 中身 |
|---|---|
| `crates/vimfps-core` | ゲームのルール (マップ生成、武器、当たり判定、bot、通信メッセージ)。サーバーとブラウザで同じものを使います |
| `crates/vimfps-wasm` | 練習モード用に `vimfps-core` をブラウザで動かす wasm |
| `crates/vimfps` | CLI (`host` / `config` / `update`)。HTTP + WebSocket サーバー、`.vimfpsrc` の読み込み、Cloudflare Quick Tunnel、自己アップデート |
| `web/assets/` | ゲームと一緒に配る素材 (同梱のスキン: `skin.json`、効果音)。[`web/assets/README.md`](web/assets/README.md) |
| `docs/` | 説明のページ ([`docs/config.md`](docs/config.md): 設定ファイルとスキン)。サイトには `scripts/md2html.py` で HTML にして載せます |
| `web/` | ブラウザのクライアント (three.js、XP 風の UI、Vim のキー処理) |

### リリース
1. `Cargo.toml` の `version` と `web/js/version.js` を上げる (通信の形を変えたら `PROTOCOL` も、`crates/vimfps-core/src/protocol.rs` と `web/js/net.js` の両方)
2. Actions → **publish-all** → Run workflow (GitHub Releases に全プラットフォームのバイナリと `SHA256SUMS`)
3. GitHub Pages は `main` への push で **pages** ワークフローが更新します (`scripts/build-site.sh` が `manifest.json` を作り、各ホストはそれを見て最新版を取得します)
