# assets — 自分で用意する素材

ゲームには同梱していない素材を置く場所です。ファイル名は**半角英数字と `.` `_` `-` だけ**にしてください
(空白や日本語を含むファイルは公開版に載りません)。

## sounds/ — 効果音

| ファイル | 鳴る場面 |
|---|---|
| `sounds/startup.wav` | スポーン時 (起動音) |
| `sounds/error.wav` | キルされた時 (エラー音) |
| `sounds/shutdown.wav` | 試合終了時 (システム終了音) |

`.wav` の代わりに `.mp3` / `.ogg` でも読みます。ファイルが無い間は短い合成音が代わりに鳴ります。
ゲーム内の `:sounds` で、どのファイルが読めているか確認できます。

## textures/ — テクスチャ

地形 (形) はそのままで、面の色を画像に置き換えます。`textures/pack.json` に、貼る場所とファイル名を書きます。

```json
{
  "ground": "grass.png",
  "wall": { "file": "brick.jpg", "size": 3 },
  "sky": "sky.jpg"
}
```

- 貼れる場所: `ground` (地面) / `wall` (建物の壁) / `roof` (屋根) / `rock` (岩) / `cover` (低い壁) / `crate` (木箱) /
  `trunk` (木の幹) / `fence` (外周のフェンス) / `leaves` (木の葉) / `tank` (戦車) / `sky` (空。横長のパノラマ画像)
- `size` は 1 枚の画像が覆う大きさ (メートル)。省略すると場所ごとの既定値です
- ここに置いた画像は、そのサーバー (または公開ページ) で遊ぶ全員に適用されます。
  自分のブラウザーだけで試すときは、ゲーム内の `:texture` を使います (ファイルを選ぶ・ドラッグ & ドロップ)
